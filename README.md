# Ultra-Premium Futuristic Cyberpunk Terminal Portfolio

This is a high-end, immersive developer portfolio built with Next.js, React, and Tailwind CSS. It features a terminal-inspired "hacker OS" aesthetic with neon lighting, CRT effects, and smooth motion interactions.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Font:** JetBrains Mono

## Key Features
- **CRT Monitor Aesthetic:** Fixed scanlines, subtle flicker, and grid backgrounds.
- **Interactive CLI Navbar:** Real-time terminal prompt with navigation.
- **Holographic Hero Section:** 3D-tilting portrait and glowing ASCII-inspired typography.
- **Terminal Project Cards:** Glassmorphism fused with CLI stats and neon borders.
- **Smooth Page Transitions:** Framer Motion orchestrated reveal animations.
- **Responsive Layout:** Optimized for all screen sizes from mobile to ultra-wide.

## How to Run
1. Install dependencies:
   ```bash
   npm install --force
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Customization
- **Colors:** Modify `tailwind.config.ts` to adjust neon intensities.
- **Content:** Update components in `src/components/` to add your own projects and experience.
